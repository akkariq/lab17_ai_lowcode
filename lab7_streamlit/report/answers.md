# Отчет по Части 2: Создание CRM-системы на low-code платформе Streamlit

## 📊 Результаты развертывания и тестирования интерфейса

В ходе выполнения лабораторной работы было разработано независимое веб-приложение на фреймворке Streamlit, интегрированное с реляционной базой данных SQLite (`crm_system.db`). Ниже представлены результаты тестирования основных модулей и представлений системы.

---

### 1. Аналитическая панель (Дашборд)
Модуль агрегирует данные из связанных таблиц `orders` и `order_items` в реальном времени, выполняя сквозной подсчет бизнес-метрик (выручка, количество транзакций) без необходимости ручного обновления.

**Интерфейс главного дашборда системы при первичном запуске:**
![Аналитический дашборд](./screenshots/Снимок%20экрана%202026-05-25%20194457.png)

---

### 2. Модуль «Клиенты»
Таблица отображает текущую базу пользователей с автоматическим вычислением общей суммы покупок по каждому клиенту (аналог функции Rollup в Airtable). Доступна разворачивающаяся форма для добавления новых записей с валидацией полей.

**Интерфейс управления базой клиентов:**
![База клиентов](./screenshots/Снимок%20экрана%202026-05-25%20194510.png)

---

### 3. Модуль «Товары»
Каталог товаров сопряжен со складским учетом. Приложение считывает актуальные цены и остатки на складе, контролируя ограничения (`CHECK`) на уровне СУБД (цена > 0, остаток >= 0).

**Складской каталог товаров:**
![Каталог товаров](./screenshots/Снимок%20экрана%202026-05-25%20194521.png)

---

### 4. Оформление комплексного заказа (CRUD Форма)
Интерактивный мастер динамически подтягивает списки клиентов и доступных товаров. Реализована валидация бизнес-логики: система сопоставляет запрашиваемое количество с фактическим остатком на складе и автоматически списывает товар при успешном проведении чека.

**Форма добавления нового заказа в CRM:**
![Форма создания заказа](./screenshots/Снимок%20экрана%202026-05-25%20194531.png)

---

### 5. Книга заказов (Журнал транзакций)
Многотабличное реляционное представление, объединяющее сущности через SQL-операторы `JOIN`. Вычисляет итоговую стоимость каждой позиции на лету.
