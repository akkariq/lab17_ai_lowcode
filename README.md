## 🎯 Цель репозитория

Репозиторий демонстрирует практическое применение двух современных парадигм ускоренной разработки программного обеспечения:

- **Генеративный ИИ** — автоматизация рутинных задач разработчика: написание функций, рефакторинг, генерация тестов, анализ качества кода.
- **Low-code фреймворки** — быстрое прототипирование полноценных бизнес-приложений с минимальным количеством шаблонного кода.

## 🏁 Общее заключение

Выполнение лабораторной работы №17 продемонстрировало **синергетический эффект** объединения двух технологических подходов: генеративного ИИ и low-code фреймворков.

ГигаChat API позволил автоматизировать ключевые рутинные задачи разработчика: за счёт контекстных LLM-промптов за минуты были сгенерированы валидаторы по стандарту RFC 5322, проведён глубокий рефакторинг legacy-кода с устранением нарушений PEP8, получены 19 единичных тестов и структурированный JSON-анализ качества кода. При этом практика показала, что модель не является автономным инструментом: выявленные логические галлюцинации в блоках `expected` и синтаксический мусор потребовали ручной верификации, что подчёркивает необходимость контроля senior-разработчика при внедрении ИИ в production-пайплайны.

Streamlit с SQLite-бэкендом продемонстрировал, что low-code подход способен полноценно заменить облачные платформы типа Airtable для локальных бизнес-задач. Реализация концепций Lookup и Rollup через нативный SQL, жёсткий контроль внешних ключей с каскадным удалением и валидация складских остатков в CRUD-форме — всё это было реализовано в единой Python-кодовой базе без привлечения отдельного frontend-стека.

**Итог:** связка «GigaChat для генерации логики + Streamlit для визуализации» формирует эффективный конвейер быстрой разработки прототипов, сокращая time-to-market для аналитических и бизнес-инструментов в 3–5 раз по сравнению с классическим full-stack подходом.

| Характеристика | GigaChat (ИИ) | Streamlit (Low-code) |
|---|---|---|
| Ключевая ценность | Генерация и рефакторинг кода за секунды | Быстрое прототипирование UI без frontend-разработки |
| Главный риск | Логические галлюцинации, синтаксический мусор | Ограниченная масштабируемость, vendor lock-in |
| Требуемые навыки | Промпт-инжиниринг, Python, code review | Python, SQL, базовые принципы UX |
| Целевой сценарий | Автоматизация рутины, генерация тестов | MVP, аналитические дашборды, внутренние CRM |
